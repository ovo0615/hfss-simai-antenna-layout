# 泛化軸：天線固定、環境變動，且變異必含拓樸

SimAI 學的是「幾何 → 響應」；via 專案的敗因是幾何用 8 個數字就寫完，
MOP 做得更好也更便宜（評分 2/6，見舊專案 `docs/SimAI 應用規劃與 Via 專案下一步.md`）。
本專案決定：同一支天線固定不動，變動的是環境——而且變異**必須包含拓樸**
（金屬件數量 0–4、種類實心塊／開槽框／L 形支架、接地面形狀矩形／切角／挖孔），
不只是連續的位置與尺寸。拓樸變異是成立條件，不是加分項：少了它，
幾何又退化成十幾個數字寫得完的題目，SimAI 相對 MOP 的正當性就消失了。

## Considered Options

- **換天線、環境固定**——天線形狀高 Q、對幾何極敏感，正是 GNN 內插的天敵；被舊專案評分表明確排除。
- **只做連續參數變異**——工程上最簡單，但會把專案做成 MOP 也能做的題目，重蹈 via 的覆轍。

## Consequences

留一種拓樸驗證（GroupKFold 以拓樸組態為 group）因此才有意義——
量的是模型沒看過的結構種類，不是同結構內插。隨機切分被明確禁止。
