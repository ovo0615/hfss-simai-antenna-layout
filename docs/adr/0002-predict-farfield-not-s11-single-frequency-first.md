# 預測目標：遠場場型＋全域係數，明確排除 S11，自 2.4 GHz 單頻起步

預測目標是遠場輻射場型（球面網格上的增益分布，SimAI 原生的「網格上的場」格式）
加上 2–3 個全域係數（峰值增益、總效率）。**S11／阻抗曲線明確排除**：
它是掃頻曲線加共振峰，環境擾動會讓諧振頻率平移，而內插器會把「平移」
抹成「變形」——這正是舊專案歸納的四個結構性錯配裡的兩個（頻率軸、共振），
也是 demo 現場最可能算出一條明顯錯誤曲線的地方。頻率先只做 2.4 GHz 單頻；
日後擴充 5 GHz 時把頻率放進 boundary conditions 當全域輸入，不改架構。

## Consequences

未來讀者會問「天線工具怎麼沒有 S11」——答案是刻意的，不是遺漏。
若有人想補上 S11 預測，必須先推翻上述錯配論證，而不是直接加欄位。
