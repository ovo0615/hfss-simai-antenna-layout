# 殘差學習與 VTP 節點特徵自第一天寫入資料格式

匯出格式自始包含三件事：（1）**殘差學習**——樣本攜帶基準場型
（乾淨平台、無金屬件的遠場），模型學的是「實際 − 基準」的擾動；
外插時退化成乾淨天線的場型而不是垃圾，這對觀眾可自由拖動的 demo
是安全網。（2）**`.vtp` 節點標註**——每個節點標明天線導體／接地面／
金屬件／介質載板；via 專案已付過學費：STL 帶節點特徵會直接拋錯，
且無標註時模型容量會浪費在重新發現已知拓樸。（3）**量測條件欄位**——
頻率、遠場取樣密度、收斂準則，匯出時強制分組、跨組不得混用
（via 專案的 20 GHz 尺規汙染教訓）。

這三項寫進格式而非事後補，因為事後補的代價是全資料集重新匯出。
