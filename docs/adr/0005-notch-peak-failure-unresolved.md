# notch 板型的峰值高估：已排除的原因與尚未解決的部分

此文件由虎門科技資深技術工程師Jeff Hong洪敬傑提供。

- 狀態：**已撤回——原本的前提是錯的**（見文末的更正）
- 日期：2026-08-29

## 現象

留出最極端的拓樸 `battery_deep` 驗證（訓練 131／驗證 29），
峰值增益誤差**完全集中在一種接地面外型**：

| 板型 | 驗證樣本 | 峰值誤差 | 場型 MAE | 判定 |
| --- | --- | --- | --- | --- |
| **`notch`** | 7 | **8.52 dB** | 1.85 dB | **stop** |
| `narrow` | 7 | 1.48 dB | 1.22 dB | 灰區 |
| `rect` | 8 | 1.46 dB | 1.19 dB | 灰區 |
| `shortgnd` | 7 | 0.67 dB | 1.34 dB | 通過 |

`notch` 的七個樣本**全部**把峰值高估，最多到 11.71 dB，
預測出 12.74 dBi 這種小型 PIFA 不可能有的增益。

## 已經排除的原因（都量過，不是推測）

1. **不是模型外推到訓練沒看過的殘差。**
   模型對 notch 預測的殘差峰值約 9.25 dB，而 notch 訓練資料裡
   最大有 11.77 dB——在範圍內。

2. **不是殘差學習本身有害。**
   殘差標準差 2.45 dB vs 絕對增益 3.24 dB，
   極端節點（|值|>10 dB）比例 0.79% vs 1.72%。
   殘差確實比絕對值好學，ADR-0004 的前提成立。
   大殘差也不是「深零點被填起來」的假象
   （殘差 >8 dB 的節點，其基準增益中位數 −0.3 dBi，
   與整體中位數 −0.2 dBi 無異）。

3. **不是資料量。**
   把非矩形板型的樣本從各 13 個增加到各 22 個（資料集 124 → 160），
   峰值誤差 **2.89 → 2.98 dB**，沒有改善。
   （同樣的作法在客戶天線上把 skill 從 0.047 拉到 0.287，所以方法本身有效。）

4. **不是缺口切到天線。**
   缺口在 x 6~34，天線在 x 44~74，**完全不重疊**。

5. **不是「模型把 rect 的反應強度套到所有板型」。**
   各板型 `battery_deep` 的真實殘差峰值：
   rect 16.7、shortgnd 17.8、**narrow 6.4、notch 8.2**。
   `narrow` 偏離 rect 的程度**比 notch 更大**，
   但 narrow 預測得好（1.48 dB）、notch 失敗（8.52 dB）。
   這個解釋不成立。

6. **不是 notch 這種幾何本身沒被正確表示。**
   同一份程式碼、同一種 `notch` 外型定義方式，換到客戶天線
   （60×40 板、蜿蜒單極）上，逐板型結果全部通過：

   | 板型 | 峰值誤差 | 判定 |
   | --- | --- | --- |
   | notch | 0.99 dB | 通過 |
   | rect | 0.48 dB | 通過 |
   | narrow | 0.42 dB | 通過 |
   | shortgnd | 0.35 dB | 通過 |

   所以問題是 **PIFA 與這個缺口之間的交互作用**，
   不是 VTP／網格對缺口的表示方式有錯。

## 值得下一個人先試的方向

**邊界條件裡完全沒有接地面外型的資訊。**
目前的全域特徵只有 `freq_ghz`、`n_metals`、`metal_volume_mm3`，
板子的外型只能靠 GNN 自己從網格幾何推斷。
加一個明確的全域特徵（接地面面積、或外型的 one-hot）是最直接的嘗試。

注意這需要重建資料集並重訓（全域特徵的數量與順序必須與訓練時一致，
否則推論會拋 numpy 廣播錯誤——`simai_worker.py` 已經把那個訊息翻譯成
看得懂的說明）。

**但先說清楚：這只是推測，還沒測。** 上面五個聽起來同樣合理的解釋都被資料推翻了。

## 目前如何處理

- **第三道守衛（輸出的物理合理性）攔住了全部 7 個**——
  預測值超出訓練看過的增益範圍就直接說「這個數字物理上不太可能」。
- 驗證報告**逐板型拆開**，直接印出「`notch` 不可用；其餘在門檻內」。
  先前只報一個總平均 2.98 dB，會讓人以為整個模型不能用，
  實際上四種板型有三種是好的。

# 更正（2026-08-29 晚間）：這份 ADR 的前提不成立

**`notch` 的峰值誤差不是一個穩定的缺陷，是單次訓練的雜訊。**

同一個設定（3 個全域特徵、160 樣本、留出 `battery_deep`）重訓一次：

| | 第一次 | 第二次 |
| --- | --- | --- |
| `notch` 峰值誤差 | **8.52 dB** | **0.88 dB** |
| 整體峰值誤差 | 2.98 dB（stop） | 1.16 dB（灰區） |
| 場型 MAE | 1.39 dB | 1.40 dB |
| skill score | 0.569 | 0.566 |

**場型 MAE 與 skill 幾乎完全一致，峰值誤差卻差了 7.64 dB。**

所以上面排除的六個解釋，全部是在解釋一個不穩定的觀測值。

## 真正的教訓（比原本的問題有用）

**極值型統計量與平均型統計量的 run-to-run 變異差了兩個數量級。**

峰值是 684 個遠場節點取 max：單一節點爆掉就主導整個數字。
場型 MAE 把同一件事平均掉，所以穩定。

先前量 run-to-run 變異時只量了 skill 與場型 MAE（變異 0.027、
逐樣本相關 0.971），就下結論「訓練是可重現的」——
**然後把那個結論套用到峰值誤差上，而峰值從來沒被量過。**

這正是本專案自己寫進文件的那條通則：
「平均型指標（MAE）會稀釋少數節點的災難性錯誤，一定要同時看極值型指標」。
當時是用來評價**模型**，卻沒有用在評價**自己的實驗方法**上。

**作法**：任何基於峰值（或其他 max/min 統計量）的結論，
都必須有**至少兩次獨立訓練**。基於 MAE／skill 的結論則不必。

## 這不影響第四道守衛

輸出的物理合理性檢查仍然必要，理由反而更強了：
既然**任何板型都可能偶發地在某個節點爆掉**，
就更需要一道「這個數字物理上不可能」的攔截，
而不是只針對某一種板型加註警語。
